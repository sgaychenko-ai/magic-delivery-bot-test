# SGG Delivery Bot 0.1.3 — песочница

Бот для доски Miro: художник кидает картинку, выбирает персонажа и тип, бот кладёт её
в колонку персонажа и в нужную секцию Comparison Deck. Повторная доставка заменяет старую на том же месте.

Эта версия работает только с тестовым батчем, который бот сам строит на доске. Рабочие доски она не трогает.
Имена персонажей в тестовом батче нейтральные (Character 01…15).

## Что в папке

| Файл | Зачем |
|---|---|
| `index.html`, `app.js` | невидимая часть: ловит картинку, брошенную на доску, и открывает панель |
| `panel.html`, `panel.js`, `panel.css` | панель бота |
| `core.js` | правила раскладки: типы доставки, секции, сетка слотов |

Сборка не нужна, это статическая страничка. Её достаточно положить на любой HTTPS-хостинг
и вписать адрес в поле App URL приложения в Miro (права: `boards:read`, `boards:write`, `identity:read`).

## Что проверить

1. **Файл на доску.** Перетащи картинку из проводника в любое место доски. Панель должна открыться сама, с превью.
2. **Файл прямо в ячейку.** Брось картинку в ячейку, например Character 05 → Render. Бот должен сам подставить персонажа и тип.
3. **Вставка из Photoshop на доску.** Открылась ли панель? Если нет — выдели картинку и нажми «Взять выделенную на доске», либо вставь прямо в панель.
4. **Раскладка.** После «Разложить» картинка появляется в колонке персонажа и в деке, исходная с доски исчезает.
5. **Замена.** Доставь того же персонажа и тот же тип ещё раз. Новая версия должна встать на те же места, версия в подписи — v2.
6. **Jira.** У колора и рендера впиши ссылку на задачу: она попадает в подпись и на саму картинку, а для этого персонажа подставляется в следующий раз.

Если в панели появилась красная строка — скопируй её текст целиком.

## Куда что ложится

| Тип | Строка в колонке персонажа | Секция деки |
|---|---|---|
| Колор скетч | Color Sketch | Approved Sketch (and WIPs) |
| Рендер | Render | Approved Renders |
| Ч/Б поза | B/W Poses | B/W Poses |
| Ч/Б дизайн | B/W Design | Approved Sketch (and WIPs) |
| Лицо | Portrait | Portraits |
| Скетч / WIP | Sketches / WIP | — |

В деке у каждого персонажа постоянный слот, там всегда последняя версия.
В колонке персонажа по умолчанию тоже замена; «Добавить рядом» оставляет предыдущую версию.

Правила лежат в начале `core.js` (`TYPES`, `DECKS`, `ROWS`) и меняются там.

## Чего пока нет

- Заливки PSD в Jira и выгрузки WIP в SharePoint/SVN.
- Смены статуса над колонкой (TO DO / WIP / REVIEW).
